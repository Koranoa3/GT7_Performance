環境：Python3.12.10

# GT7 Hub PC

## セットアップ

1. Python3.12.10をインストール
2. 仮想環境を作成
   ```bash
   python3.12 -m venv .venv
   ```
3. 仮想環境をアクティベート(Windows)
    ```bash
    .venv\Scripts\activate
    ```
4. 依存関係をインストール
   ```bash
    pip install -r requirements.txt
    ```
5. アプリケーションを起動
   ```bash
    python main.py
    ```
